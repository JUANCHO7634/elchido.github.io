Recursividad

La recursividad es una técnica de programación en la que una función se llama a sí misma para resolver un problema, dividiéndolo en problemas más pequeños.

Conceptos fundamentales

La recursividad permite resolver problemas complejos mediante llamadas repetidas a una misma función.

?

¿Qué es la recursividad?

Es una técnica donde una función se invoca a sí misma hasta alcanzar una condición que detiene el proceso.

⚙

Procedimientos recursivos

Son funciones que contienen una llamada a sí mismas. Se utilizan en árboles, búsqueda, ordenamiento, matemáticas y procesamiento de estructuras.

★

Características

Toda recursividad necesita un caso base y un caso recursivo que permita avanzar hacia la solución.

▮

Complejidad computacional

Los algoritmos recursivos pueden consumir tiempo y memoria dependiendo de la cantidad de llamadas realizadas.

¿Cómo funciona?

Un procedimiento recursivo divide un problema en partes más pequeñas hasta llegar a un caso base.

MATEMÁTICAS

Factorial

El factorial de un número entero positivo se obtiene multiplicando ese número por todos los enteros positivos anteriores.

n! = n × (n - 1)!

Por ejemplo:

5! = 5 × 4 × 3 × 2 × 1 = 120

Ejemplo funcional

Resultado: 120

Código Java

public static int factorial(int n) {

    if (n == 0) {
        return 1;
    }

    return n * factorial(n - 1);
}
SECUENCIA

Fibonacci

La sucesión de Fibonacci se obtiene sumando los dos valores anteriores para obtener el siguiente.

F(n) = F(n-1) + F(n-2)
0, 1, 1, 2, 3, 5, 8, 13...

Ejemplo funcional

Fibonacci(8) = 21

Código Java

public static int fibonacci(int n) {

    if (n <= 1) {
        return n;
    }

    return fibonacci(n - 1)
         + fibonacci(n - 2);
}
RECURSIVIDAD

Torres de Hanói

Es un problema clásico que consiste en mover una torre de discos desde una columna de origen hasta una columna destino utilizando una columna auxiliar.

T(n) = 2T(n-1) + 1

Nunca se puede colocar un disco grande sobre uno pequeño.

Para 3 discos se necesitan 7 movimientos.

Código Java

public static void hanoi(
    int n,
    char origen,
    char auxiliar,
    char destino) {

    if (n == 1) {

        System.out.println(
            origen + " -> " + destino
        );

        return;
    }

    hanoi(
        n - 1,
        origen,
        destino,
        auxiliar
    );

    System.out.println(
        origen + " -> " + destino
    );

    hanoi(
        n - 1,
        auxiliar,
        origen,
        destino
    );
}

Conclusión

La recursividad es una herramienta fundamental en las ciencias computacionales porque permite solucionar problemas complejos dividiéndolos en problemas más pequeños. Aunque puede requerir mayor cantidad de memoria y tiempo en determinados casos, resulta especialmente útil para trabajar con estructuras jerárquicas, algoritmos matemáticos, búsqueda, ordenamiento y gráficos.

Comprender la recursividad permite desarrollar algoritmos más organizados y facilita el análisis de diferentes problemas computacionales.
